    Connect a courier once. Sending, tracking and Shopify updates then run on their own.

    Find these in Pathao Merchant Panel → Developers API. Secrets are stored encrypted.

    Callback URL
    1. Pathao Merchant Panel → Developers API → Webhook integration.
    2. Paste the Callback URL, enter the same secret key, save.

    Default delivery type

    Steadfast portal → API → Your API keys. Make a key just for ShipBridge, so you can revoke it without affecting anything else. The secret key is stored encrypted.

    Callback URL
    1. Steadfast portal → API → Webhook.
    2. Paste the Callback URL there. Leave the auth token empty — it's not needed.
    3. Save in Steadfast, then press Save here.
    4. Steadfast sends updates when a parcel's status changes (not when you save). Until the first one, ShipBridge checks Steadfast every minute, so statuses still update.
